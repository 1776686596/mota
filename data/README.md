# 测试数据集说明

本目录包含用于测试 SciPlot-Copilot 的数据集：

## 原有数据集（科研相关）
- `cell_viability.csv` - 细胞活力测试数据
- `enzyme_activity.csv` - 酶活性分析数据
- `material_test.csv` - 材料测试数据
- `xrd_analysis.csv` - XRD 分析数据

## 新增数据集（通用科学数据）
- `iris.csv` - 鸢尾花数据集（150行，5列）
  - 特征：萼片长度、萼片宽度、花瓣长度、花瓣宽度
  - 分类：3种鸢尾花品种
  - 适用场景：分类分析、散点图、箱线图

- `penguins.csv` - 企鹅数据集（344行，7列）
  - 特征：喙长、喙深、鳍长、体重
  - 分类：3种企鹅物种
  - 适用场景：多变量分析、相关性分析、分组比较

- `tips.csv` - 餐厅小费数据集（244行，7列）
  - 特征：账单金额、小费、性别、时间、星期
  - 适用场景：回归分析、分类比较、时间序列

- `diamonds.csv` - 钻石数据集（53940行，10列）
  - 特征：克拉、切工、颜色、净度、价格等
  - 适用场景：大数据集可视化、价格预测、多维分析

## 使用建议
1. 小数据集（iris, tips）适合快速测试
2. 中等数据集（penguins）适合探索性分析
3. 大数据集（diamonds）适合测试性能和复杂可视化
4. 科研数据集适合测试专业场景
