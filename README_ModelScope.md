# 📊 SciPlot-Copilot

> 🚀 AI 驱动的下一代科研可视化与逻辑梳理平台

融合大语言模型智慧，一键生成 Nature 级科研图表，智能梳理复杂实验逻辑。让数据说话，让逻辑可见。

## ✨ 核心功能

### 📈 智能绘图工作室
- **自然语言绘图**：用中文描述你想要的图表，AI 自动生成专业代码
- **多种图表类型**：支持散点图、折线图、柱状图、箱线图、热力图、小提琴图等
- **Nature 级样式**：内置多种顶刊风格模板（Nature、Science、Cell 等）
- **实时预览**：即时查看图表效果，支持交互式调整
- **代码透明**：完整展示生成的 Python 代码，方便学习和二次修改

### 🧠 逻辑思维导图
- **智能逻辑梳理**：AI 分析实验数据，自动提取关键逻辑关系
- **可视化展示**：生成清晰的思维导图，展示数据间的因果关系
- **支持多种格式**：导出为图片或 Mermaid 代码

### 🔬 统计分析工具 (新功能)
- **假设检验**：t 检验、ANOVA、卡方检验、Mann-Whitney U 检验等
- **回归分析**：线性回归、多元回归，自动计算 R²、RMSE 等指标
- **相关性分析**：Pearson、Spearman、Kendall 相关系数矩阵
- **正态性检验**：Shapiro-Wilk 检验，Q-Q 图可视化

### 🔧 数据预处理 (新功能)
- **缺失值处理**：均值/中位数/众数填充、删除缺失行
- **数据转换**：标准化、归一化、对数转换、独热编码
- **数据筛选**：按条件筛选行、选择保留列
- **数据采样**：随机采样、分层采样、等间隔采样

### 💾 项目管理 (新功能)
- **保存项目**：保存数据、图表历史、对话记录、逻辑图
- **加载项目**：随时恢复之前的工作进度
- **导出报告**：生成 Markdown 格式的分析报告

## 🚀 快速开始

### 1. 配置 API
在侧边栏的「⚙️ API 配置」中设置：
- **API Base URL**：LLM 服务地址（支持 OpenAI 兼容接口）
- **API Key**：你的 API 密钥
- **模型**：选择使用的模型（如 gpt-4、gpt-3.5-turbo 等）

### 2. 上传数据
- 支持 CSV、Excel 格式
- 内置多个示例数据集可供体验

### 3. 开始使用
- **绘图**：在「智能绘图工作室」输入绘图需求，如"绘制一个展示不同物种花瓣长度分布的箱线图"
- **逻辑梳理**：在「逻辑思维导图」中分析数据关系

## 📦 技术栈

- **前端框架**：Streamlit
- **可视化库**：Matplotlib、Seaborn、Plotly
- **AI 引擎**：OpenAI 兼容 API
- **数据处理**：Pandas、NumPy
- **统计分析**：SciPy、Scikit-learn、Statsmodels

## 🎨 支持的图表类型

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| 散点图 | 展示两变量关系 | 相关性分析 |
| 折线图 | 展示趋势变化 | 时间序列 |
| 柱状图 | 比较分类数据 | 分组对比 |
| 箱线图 | 展示数据分布 | 统计分析 |
| 热力图 | 展示矩阵数据 | 相关性矩阵 |
| 小提琴图 | 展示分布密度 | 分布对比 |
| 直方图 | 展示频率分布 | 数据分布 |
